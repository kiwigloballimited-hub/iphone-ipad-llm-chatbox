# Screenshots / 截图

Put screenshots here, then uncomment the screenshot table in the main `README.md`.
把截图放在这个文件夹里，然后在主 `README.md` 中取消截图表格的注释。

Suggested file names / 建议的文件名：

| File | Content |
|---|---|
| `agents.png` | Agent list / 助手列表 |
| `chat.png` | A conversation / 聊天界面 |
| `persona.png` | Persona editor / 人格设定 |
| `video.png` | Video frame picker / 视频抽帧 |
| `browser.png` | Browser assistant / 浏览器助手 |
| `ipad.png` | iPad layout / iPad 界面 |

Tip: on iPhone, press Side button + Volume Up to take a screenshot, then AirDrop it to your Mac.
提示：iPhone 上同时按「侧边按钮 + 音量加」截图，再用隔空投送传到 Mac。
